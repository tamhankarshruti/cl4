What does ETL stand for?
ETL stands for Extract, Transform, and Load.
What is the purpose of ETL?
ETL is used to collect, clean, and load data for analysis.
Which tool was used for ETL and visualization?
Microsoft Power BI was used.
Which dataset was used in this experiment?
Titanic dataset was used.
What happens in the Extract phase?
Data is imported from external sources.
What happens in the Transform phase?
Data is cleaned and modified.
What happens in the Load phase?
Processed data is loaded into Power BI for analysis.
What is Power Query Editor?
It is a tool used for data transformation in Power BI.
Why are null values removed?
To improve data quality and accuracy.
Why are data types changed during transformation?
To ensure correct calculations and analysis.
What is a dashboard?
A dashboard is a collection of visual reports on one page.
What is a slicer in Power BI?
A slicer is an interactive filter for reports.
